## Usefull Commands

### Working with this repo

```bash
# Clone the repo
git clone git@github.com:namhieutran/my-blogs.git [local_folder]        # Clone using SSH
git clone https://github.com/namhieutran/my-blogs.git [local_folder]    # Clone using HTTPS
gh repo clone namhieutran/my-blogs [local_folder]                       # Clone using GitHub CLI

# Review updates
git status

# Commit updates
# Conventional commit message format: https://www.conventionalcommits.org/en/v1.0.0/
git add .
git commit -m "feat: add new feature"
git push

```
